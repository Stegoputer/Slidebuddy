SEKTIONSPLANUNG (EBENE 2):

Du erhältst ein Kapitel mit einem indizierten QUELLPOOL. Plane für dieses
Kapitel die exakt geforderte Anzahl Folien — jede Folie muss inhaltlich aus
dem Pool stammen. Erfinde keine Inhalte, die nicht im Pool stehen.

Verwende AUSSCHLIESSLICH die Templates aus dem Abschnitt VERFUEGBARE TEMPLATES
weiter unten. Erfinde KEINE eigenen Template-Namen — nutze nur die dort
aufgelisteten template_type Werte.

Für jede Folie definiere:
- title: prägnanter Folientitel (kein generisches "Einleitung", "Übersicht")
- brief: 2–3 Sätze, was konkret auf der Folie steht (NICHT generisch)
- template_type: muss exakt einem verfuegbaren Template entsprechen
- source_indices: Liste der Pool-Indizes (0-basiert, integer), die diese
  Folie inhaltlich abdeckt. JEDE Folie referenziert mindestens einen Index,
  sofern der Pool nicht leer ist.

Antworte AUSSCHLIESSLICH im JSON-Format:
{
    "slides": [
        {
            "title": "str",
            "brief": "str",
            "template_type": "str",
            "source_indices": [int, ...]
        }
    ],
    "reasoning": "Kurze Begründung für Reihenfolge und Index-Zuweisung"
}

RICHTLINIEN:
- Index-Treue: Verwende NUR Indizes, die im Pool existieren. Keine erfundenen
  Indizes, keine Negativzahlen, keine Strings.
- Roter Faden: Folge wenn möglich der aufsteigenden Reihenfolge der Indizes.
  Inhaltlich verwandte Indizes können auf eine Folie zusammengefasst werden;
  ein dichter Index darf auf zwei Folien aufgeteilt werden.
- Template-Variation: Niemals mehr als 2 gleiche Templates in Folge — variiere
  passend zum Inhalt (Vergleiche → Vergleichs-Template, Schritte →
  Aufzaehlungs-Template, Details → Detail-Template, Zitate → Zitat-Template).
- Kein "reused_slide_id"-Feld in dieser Phase — Slide-Reuse passiert separat
  in der Generierung.
